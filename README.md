# ⚡ TaskForge — Daily Task Manager

A premium, dark-themed personal task management app built to help you crush your daily goals. Track habits like GitHub commits, AWS reviews, DSA practice, and more — all in one sleek interface.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔁 **Daily Habits** | 4 pre-loaded recurring tasks auto-populate every day |
| 📊 **Progress Ring** | Animated circular progress indicator for daily completion |
| 🔥 **Streak Tracker** | Counts consecutive days with all tasks completed |
| 🎉 **Confetti Celebration** | Particle explosion when you finish all tasks for the day |
| 🏷️ **Category Filters** | Organize tasks by Dev Work, Cloud, Learning, Editing, General |
| ➕ **Quick Add** | Add tasks with category & priority in one click |
| 📅 **Date Navigation** | Browse past and future days to review progress |
| 💾 **Persistent Storage** | All data saved to `localStorage` — survives refresh |
| 📱 **Fully Responsive** | Works beautifully on desktop, tablet, and mobile |
| 🌙 **Dark Glassmorphism UI** | Premium dark theme with blur effects & micro-animations |

## 🚀 Getting Started

No build tools, no dependencies, no server required — just open and go.

### Option 1: Open directly
```
Just double-click index.html in your browser
```

### Option 2: Clone & open
```bash
git clone https://github.com/<your-username>/To-Do-App.git
cd To-Do-App
start index.html   # Windows
open index.html     # macOS
xdg-open index.html # Linux
```

- **HTML5** — Semantic markup with accessibility attributes
- **CSS3** — Custom properties, glassmorphism, keyframe animations, responsive grid
- **Vanilla JavaScript** — Zero dependencies, pure DOM manipulation
- **localStorage API** — Client-side data persistence

---

## 📸 How It Works

1. **Open the app** — Your daily habits are auto-loaded
2. **Check off tasks** — Progress ring and stats update in real-time
3. **Add custom tasks** — Pick a category and priority level
4. **Complete everything** — Watch the confetti explode 🎊
5. **Build your streak** — Come back tomorrow and keep the 🔥 alive
6. **Navigate dates** — Review what you accomplished on any day
